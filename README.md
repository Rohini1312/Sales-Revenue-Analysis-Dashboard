# Sales & Revenue Analysis Dashboard

## 📊 Project Overview

Sales & Revenue Analysis Dashboard is a data analytics project developed using Python, Pandas, NumPy, Matplotlib, Seaborn, and Streamlit.

The project analyzes sales data to understand revenue trends, product performance, category-wise sales, regional performance, customer contribution, and payment methods.

## 🎯 Objectives

- Analyze sales and revenue performance
- Identify top-performing products
- Analyze category and regional sales
- Identify top customers
- Understand payment method patterns
- Visualize monthly revenue trends
- Build an interactive dashboard

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Streamlit

## 📌 Dashboard Features

- Total Revenue
- Total Orders
- Total Customers
- Quantity Sold
- Average Order Value
- Monthly Revenue Trend
- Revenue by Category
- Top 5 Products
- Revenue by Region
- Payment Method Distribution
- Top 10 Customers
- Interactive Filters
- Downloadable Data
